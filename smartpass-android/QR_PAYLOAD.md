## 1. System-Wide Investigation Findings

### 1.1 Backend Inspection (`smartpass-backend`)
- **Card Model (`models/Card.js`):**
  - Field: `qrToken: { type: String, unique: true, required: true, trim: true }`
  - Generation: `crypto.randomBytes(32).toString('hex')` (in `services/cardService.js:53` and `services/emergencyService.js:97`).
  - Length: Exactly **64 hex characters** (`^[0-9a-fA-F]{64}$`).
- **Endpoints consuming QR values:**
  1. `POST /api/cards/verify`: Accepts `{ qrToken?: string, cardCode?: string, nfcUid?: string }`.
     - Validates: Exactly one identifier must be provided.
     - Resolves card and returns: `{ card: { id, cardCode, status, expiresAt }, owner: { fullName, studentCode, className } }`.
  2. `POST /api/attendance/check`: Accepts `{ qrToken, cardCode, nfcUid, classSession, subject }`.
  3. `POST /api/wallet/pay`: Accepts `{ qrToken, cardCode, nfcUid, amount }`.
  4. `POST /api/parking/check-in`: Accepts `{ qrToken, cardCode, nfcUid, vehiclePlate }`.
  5. `POST /api/parking/check-out`: Accepts `{ qrToken, cardCode, nfcUid }`.
  6. `GET /api/emergency/public/:qrToken`: Path parameter `:qrToken` (resolves card by `qrToken`, checks active status, and returns public visible emergency fields).
  7. `POST /api/emergency/me/rotate-qr`: Generates a new 64-char hex string, updates `card.qrToken`, and invalidates old token immediately.

## 2. Payload Architecture Answers

### Q1: What is the raw string inside the QR code?
The raw QR payload is the card's **64-character lowercase hexadecimal token** (`card.qrToken`), generated by 32 bytes of cryptographic randomness.
In addition, to support public scans from third-party camera apps (e.g. standard phone camera or public emergency responders), the system supports URL format:
- `https://smartpass.edu/emergency/public/<64-char-hex>`
- `https://<host>/api/emergency/public/<64-char-hex>`
- `smartpass://emergency/<64-char-hex>`

### Q2: Is it a raw token, JSON string, URL, or cardCode?
- Primary on-device QR: **Raw hex string** (e.g. `cdc040ad37ddfdfc53acffd172d14062f2cfdc403f5a121e340eba2c628ad51c`).
- Web URL / Deep-link: Supported as a parsed variant where the parser strips prefix and extracts the trailing 64-character hex token.
- Manual Input: Supports both raw 64-character `qrToken` AND physical `cardCode` (e.g. `CARD-STU001` or `SP-SEED-10001`).

### Q3: How does the scanner distinguish between a Student Card QR and an Emergency QR?
**They are the EXACT SAME token.**  
In SmartPass architecture, each physical/digital card has a single cryptographic `qrToken` stored in `Card.qrToken`.
- **Contextual routing determines the action:**
  - **Public / Unauthenticated Scanner OR Public Emergency Scan Button:** If the user scans the QR from the Emergency viewer or while unauthenticated, it opens `PublicEmergencyScreen` (`GET /api/emergency/public/:qrToken`).
  - **Staff Scanner (Librarian, Canteen, Parking, Attendance):** Resolves the card via the role's business endpoint (or `POST /api/cards/verify`) using `{ qrToken: parsedToken }`.
  - **Student Self-Card:** Displays this exact `qrToken`. When rotated (`/rotate-qr`), both card verification and emergency public access update synchronously.

### Q4: Regex & Validation Patterns
1. **Raw QR Token:**
   - Pattern: `^[0-9a-fA-F]{64}$`
2. **Emergency URL:**
   - Pattern: `^https?://.*/(?:emergency/public|public_emergency)/([0-9a-fA-F]{64})/?$`
3. **Card Code (Manual input):**
   - Pattern: `^[A-Za-z0-9\-]{4,32}$`

## 4. Parser Interface Contract (Kotlin)

```kotlin
sealed class QrPayload {
    data class Token(val value: String) : QrPayload()
    data class CardCode(val value: String) : QrPayload()
    data class Invalid(val reason: String) : QrPayload()
}

object QrPayloadParser {
    private val HEX_TOKEN_REGEX = Regex("^[0-9a-fA-F]{64}$")
    private val URL_TOKEN_REGEX = Regex("(?:emergency/public|public_emergency)/([0-9a-fA-F]{64})")
    private val CARD_CODE_REGEX = Regex("^[A-Za-z0-9\\-]{4,32}$")

    fun parse(raw: String): QrPayload {
        val trimmed = raw.trim()
        if (HEX_TOKEN_REGEX.matches(trimmed)) {
            return QrPayload.Token(trimmed.lowercase())
        }
        val match = URL_TOKEN_REGEX.find(trimmed)
        if (match != null) {
            return QrPayload.Token(match.groupValues[1].lowercase())
        }
        if (CARD_CODE_REGEX.matches(trimmed)) {
            return QrPayload.CardCode(trimmed)
        }
        return QrPayload.Invalid("Mã không hợp lệ hoặc không thuộc hệ thống SmartPass")
    }
}
```
